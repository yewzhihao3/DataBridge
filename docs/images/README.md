# README screenshot checklist

The repository currently has no safe, browser-captured README gallery. Capture these images from a disposable local/demo workspace after starting the application with `npm run dev`.

Use a 1440 × 900 browser viewport, hide browser chrome, and crop to the application canvas. Use fake names and workbook data only. Do not include email addresses, passwords, invitation links/tokens, browser bookmarks, devtools, or localhost chrome in the image.

| File | Screen | Suggested state |
| --- | --- | --- |
| `dashboard-dark.png` | Dashboard | Dark Orange, representative metrics and trend cards |
| `ingestion-smart-extraction.png` | Ingestion Studio | An XLSX selected with deterministic recommendations visible |
| `batch-review.png` | Batch review | Mixed statuses: Ready, Needs Review, Duplicate or Failed; no private filenames |
| `data-explorer.png` | Data Explorer | Filtered, realistic standardized records and pagination/filter UI |
| `settings-members.png` | Settings → Members | Fake workspace, roles, and no invitation token/link visible |
| `dashboard-light.png` | Dashboard | Light Blue or Emerald, same clean application-only crop |

After capturing, save the PNGs in this directory with the exact filenames. The root README already references them, so GitHub will render the gallery automatically.
